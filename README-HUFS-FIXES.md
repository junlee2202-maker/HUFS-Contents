# HUFS Contents — 수정본

기존 Figma Make ZIP을 바탕으로 변경했습니다.

## 이번 코드 수정
- Play 객관식: 오답 후 다른 답 재선택 가능, 정답 이후 선택 잠금
- Vocabulary Play: 단어/문장 영어 음성 및 다시 듣기 버튼
- Speaking Play: 질문 다시 듣기 버튼
- 진단 결과 화면: 오른쪽 상단 '초기 예상' 표시 제거
- Play 오답 피드백: 재도전 가능함을 명시
- 음성 재생 실패 시 상태 메시지 표시

## 원본 코드에 이미 구현되어 있던 기능
- A1~C2 가중 점수 진단, 진단 재응시, 어학 자격 목표
- 결과 페이지 학습 여정 설명, Learn 선택 잠금 및 오답 설명
- Writing 기본 규칙 기반 평가, Speaking 추천 답변

## 실행
Node.js 설치 후 `npm install` 및 `npm run dev` 실행.

## 검증 제한
현재 실행 환경에서 패키지 설치가 완료되지 않아 실제 빌드 및 브라우저 동작 테스트는 수행하지 못했습니다. 음성 재생은 브라우저의 Web Speech API 지원 및 사용자 음성 설정에 따라 달라집니다. Writing 평가는 규칙 기반으로 자유 서술을 완벽하게 평가하지 못합니다. 진단 결과는 공식 CEFR 인증이 아닌 프로토타입 추정입니다.
